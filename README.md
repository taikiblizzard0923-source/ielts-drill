# IELTS 2週間ドリル

IELTS Academic（2026/12/13受験、Overall 5.0→5.5）向けの14日分の学習ページ。オリジナル予想問題（L・R 260点分＋Writing・Speaking）、解説・全訳、リスニング音声付き。

公開URL: https://taikiblizzard0923-source.github.io/ielts-drill/

- 画面: index.html（tools/build.py で src_body.html・src_extra.css・base_teap.html から生成）
- データ: data/*.js（仕様は docs/SPEC.md）
- 音声: tools/gen_ielts.py（Kokoro TTS）
- 検査: tools/check_ielts.js, tools/e2e_ielts.js, tools/blind_dump.js, tools/blind_compare.js
